# Implementation Plans

Use this directory for implementation plans when a change warrants one.
Requirements and acceptance contracts belong in
[specifications](../specs/README.md); task progress, owners and dependencies live
in GitHub Issues, with implementation/validation recorded in PRs.

Completed plans should be retired after durable decisions, requirements and
validation evidence have been preserved. Do not restore completed instructions
or use this directory as another status tracker.

The remaining [Phase 1 migration reference](dutchmate_phase1_v2_coding_agent_plan.md)
is historical, not an active plan. It preserves the original Git location and
links to current authorities. Physical acceptance criteria remain in the
specification and measurements in hardware validation records. MCP and
CI/distribution documents are active contracts under `docs/specs/`.
