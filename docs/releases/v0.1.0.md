# DUTchMate v0.1.0

DUTchMate v0.1.0 is the first public release of the Python host software for
AI-assisted embedded debugging. It provides one installable tool surface for
the Device Core Service, command-line workflows, and local MCP integration.

## Installation

Install the public aggregator with either supported tool installer:

```bash
uv tool install dutchmate==0.1.0
```

```bash
pipx install dutchmate==0.1.0
```

The installation provides `dutchmate`, `dm`, `dutchmate-service`, and
`dutchmate-mcp`.

## Highlights

- Basic USB-to-UART and Enhanced RP2350 Debug Helper backends share one Device
  Core session and evidence pipeline.
- Deterministic CLI workflows cover service lifecycle, DUT configuration,
  capture, UART, GPIO/control operations, sessions, logs, baselines, and waits.
- The local stdio MCP server exposes the nine documented Device Core tools for
  coding-agent integration without duplicating hardware ownership.
- Structured sessions retain lifecycle, UART, hardware, integrity, reconnect,
  and comparison evidence.
- All five public distributions use synchronized `0.1.0` versions and exact
  first-party dependency constraints.
- The release artifacts passed clean-install command checks, MCP discovery,
  TestPyPI verification, and production PyPI filename/SHA-256 verification.

## Published distributions

- `dutchmate`
- `dutchmate-core`
- `dutchmate-cli`
- `dutchmate-service`
- `dutchmate-mcp-server`

`dutchmate-debug-agent` remains provider-disabled and workspace-tested. Its
first public distribution is deferred to the coordinated v0.2.0 release.

## Support boundaries

- Linux and macOS are supported initially; Windows support is not claimed.
- Firmware source and reproducible compile CI are included in the repository,
  but this release does not publish versioned firmware binaries.
- The legacy EAGLE hardware design is excluded from the Python distributions
  and remains outside the new license grants. The replacement KiCad design and
  its provenance audit are future work.
- Automated physical HIL is not part of this release.
